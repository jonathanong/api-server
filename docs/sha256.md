# SHA-256

`@jongleberry/api-server/sha256` exports a small Node-only digest helper:

```ts
import { sha256 } from "@jongleberry/api-server/sha256";

const digest = sha256("payload"); // Buffer
```

`sha256(input)` accepts a string or any `NodeJS.ArrayBufferView` and returns the raw SHA-256 bytes
as a `Buffer`. The server's automatic ETag generator uses this same helper, preserving its existing
base64url, quoted ETag output.
